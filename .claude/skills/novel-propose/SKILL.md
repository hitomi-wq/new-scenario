# Novel Propose Skill

Netflixの人気作品トレンドを分析し、世界市場で受け入れられそうな日本発コンテンツの企画を立案するスキル。

## ワークフロー

作業前にタスクリストを作り、順番に進めること。

### 1. トレンド調査

WebSearch / WebFetch を使い、直近のNetflixグローバル人気作品の傾向を調査する。調べる観点:

- Netflix Top 10 グローバル（直近〜過去1年程度）にランクインした作品とジャンル
- 既に成功した日本発コンテンツ（例: アニメ作品、実写ドラマ、リアリティ番組など）が世界でなぜ受けたか
- 海外で人気が出ている非日本作品（韓国・他国）の成功要因と、日本コンテンツへの応用可能性
- 視聴者層・配信時期・話数構成などのフォーマット面の傾向

調査結果は箇条書きで要点を整理する。生成元のURLは検証用に記録しておく。

### 2. 傾向分析

調査結果から、以下を抽出する:
- 海外で支持されやすいジャンル・テーマ（例: サスペンス、SF、ヒューマンドラマ、ダークな世界観 等）
- 「日本らしさ」として強みになりうる要素（美意識、伝統文化、都市と田舎の対比、職人技、季節感、社会的テーマ等）
- フォーマット面のベストプラクティス（話数、エピソード尺、シーズン構成）

### 3. 企画案の作成

分析結果を踏まえ、新規コンテンツ企画を2〜3案作成する。各企画には以下を含める:

- **タイトル（仮）**
- **ジャンル / フォーマット**（ドラマ全何話、アニメ、実写映画など）
- **ログライン**（1〜2文で内容を要約）
- **あらすじ**（5〜10行程度）
- **「日本らしさ」の活用ポイント**（舞台・文化要素・テーマ）
- **海外でウケる要素との対応**（手順2の分析結果のどれに合致するか明示）
- **想定ターゲット層・配信形態の想定**

### 4. 企画書の出力

企画案をまとめた企画書を Markdown ファイルとして作成する。ユーザーから出力先の指定がなければ、作業ディレクトリに `novel-proposal-<連番>.md` のような名前で保存することをユーザーに確認した上で作成する。

企画書には以下を含める:
- 調査の要約（トレンド分析セクション）
- 企画案（2〜3案、上記項目を満たす）
- 参考にした情報源（URL一覧）

## 注意点

- 実在する作品・人物・統計データを扱う際は、WebSearch/WebFetchで取得した情報に基づいて記述し、推測で具体的な数値や事実を作り出さない。
- 企画はあくまで叩き台であることを明示し、最終的な採否はユーザーが判断するものとして提示する。
- 著作権のある既存作品の模倣（タイトル・キャラクター・ストーリーの流用）は行わず、オリジナルの企画とする。
